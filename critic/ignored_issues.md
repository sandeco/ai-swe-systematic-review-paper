# Problemas Já Conhecidos, Ignorar em Novas Análises

Este arquivo lista problemas que o autor já conhece e que **não devem ser levantados novamente** pelo paper-critic. São escolhas intencionais, limitações já assumidas ou pontos que o autor decidiu não tratar nesta linha do artigo.

Ao iniciar uma análise, leia esta lista e exclua qualquer crítica que se enquadre nos itens abaixo.

Formato de cada entrada:

```
## <Título curto do problema>

- Descrição em uma ou duas frases do que não deve ser apontado e por quê (decisão do autor, data se relevante).
```
